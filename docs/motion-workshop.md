# GPT 동작 그림 → 앱용 프레임

1. 등록 화면 맨 위 **동작 만들기 · GPT 그림을 앱에서 정리**에 이름과 특징을 적습니다.
2. **기준 캐릭터 프롬프트 복사**를 누르고 ChatGPT에 원본 사진과 함께 붙여넣습니다.
3. 얼굴·귀·무늬가 맞는 기준 캐릭터 이미지를 확정합니다.
4. 걷기·대기/깜빡임·수면·먹기를 각각 선택하고 동작 프롬프트를 복사합니다.
   ChatGPT에는 원본 사진 대신 확정한 기준 캐릭터 이미지를 첨부합니다.
5. 완성된 PNG를 해당 동작의 **그림 가져오기**로 가져옵니다.
6. 프레임을 하나씩 선택하거나 재생합니다. 뒤집힌 프레임은 **선택 프레임 좌우 반전**,
   순서는 **순서 앞으로/뒤로**로 수정합니다.
7. 네 동작을 확인한 후 확인 체크 → **보관함에 저장**을 누릅니다.
8. 아래 결과 미리보기의 **바탕화면에 데려오기**로 적용합니다.

## 규격

| 동작 | 시트 | 프레임 수 |
|---|---|---|
| 걷기 | 4열 × 2행 | 8 |
| 대기·깜빡임 | 2열 × 1행 | 2 |
| 수면 | 2열 × 1행 | 2 |
| 먹기 | 2열 × 1행 | 2 |

각 칸은 정사각형이며 사방에 여백이 있어야 합니다. PNG 한 장당 최대 20MB.
실제 투명 배경을 권장하며 단색 자홍색 배경은 선택적으로 제거합니다.
흰색·체크무늬 배경을 자동으로 투명 처리하지는 않습니다.

## 정렬 방식과 한계

- 앱은 새 그림을 생성하지 않고 픽셀을 분할·정렬합니다. 이 과정은 API·Ollama·ComfyUI가 필요 없습니다.
- 같은 동작의 프레임들은 공통 크기와 가로 기준을 사용합니다. 발바닥은 같은 높이에 맞춥니다.
- 왼쪽 걷기는 오른쪽 걷기를 반전하므로 별도 생성하지 않습니다.
- 프레임 방향이나 발의 자세를 AI로 판정하지 않습니다. 적용 전에 사람이 확인해야 합니다.
- 좌우 반전·순서 변경으로 다른 체형이나 잘못 그려진 다리까지 고칠 수는 없습니다.
- 선택 프레임 반전은 그 프레임의 비대칭 무늬도 함께 반전합니다.
- 준비한 프레임은 이 PC의 임시 작업 상태로 저장됩니다. 편집하면 확인 체크가 해제됩니다.
- 쓰다듬기에는 대기의 행복한 깜빡임을 사용합니다. 기존 20프레임 재생 규격과 호환됩니다.

## 검증

자동 테스트는 분할 규격·투명도·정렬 기준·프레임 반전·잘못된 입력 거부를 검사합니다.
실제 Electron 화면에서 기존 터치 그림을 테스트용 시트로 조립하여 네 동작 업로드,
확인·저장·미리보기·바탕화면 적용을 검증합니다. 이 시트는 새 GPT 생성 결과가 아닙니다.
