# 4×4 시트 한 장으로 데려오기 (v0.8.2)

1. 등록 화면 맨 위에서 이름과 특징을 입력합니다.
2. 새로 만들 때는 **① 프롬프트 복사** → **② ChatGPT 열기** 후 원본 사진을 직접 첨부하고 붙여넣습니다.
3. 이미 완성된 시트가 있다면 2번은 건너뛰고 **③ 동작 시트 가져오기**에서 PNG를 선택합니다.
4. 가져오기에 성공하면 보관함에 저장됩니다. 아래 미리보기에서 동작을 확인합니다.
5. **바탕화면에 데려오기**로 적용합니다.

## 시트 규격

정사각형 PNG 한 장, 4열 × 4행, 최대 20MB, 실제 투명 배경이 필요합니다.
각 칸의 중앙 65% 안에 캐릭터를 배치하고 사방에 최소 15% 투명 여백을 둡니다.

- 1~2행: 오른쪽을 향하는 걷기 8프레임
- 3행: 대기, 깜빡임, 수면 2프레임
- 4행: 식사 2프레임, 편안한 표정 2프레임

앱이 16칸을 분할하고 기존 20프레임 재생 규격에 맞춰 저장합니다.
왼쪽 걷기는 오른쪽 걷기를 반전합니다. 쓰다듬기는 깜빡임 프레임을 사용합니다.

## 주의할 점

사진은 ChatGPT에 자동 전송되지 않습니다. 이 수동 흐름에는 API 키가 필요 없습니다.
앱은 잘못 그려진 다리나 시트의 색 번짐을 AI로 자동 보완하지 않습니다.
칸 경계에 캐릭터나 잔여 픽셀이 닿으면 가져오기가 거부되고 오류가 표시됩니다.
각 프레임을 개별 중심 정렬하므로 생성된 자세에 따라 움직임이 흔들릴 수 있습니다.
동작별 업로드 편집기는 기본 등록 화면에서 제거했습니다.
