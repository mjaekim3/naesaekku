# 등록하기 (v0.9.1)

1. 우리 아이 소개에서 이름과 특징을 입력합니다.
2. 너부리 캐릭터를 바탕으로 만든 픽셀 아트 / 포근한 일러스트 예시를 보고 스타일을 고릅니다.
3. 프롬프트 복사 → ChatGPT 열기 → 원본 반려동물 사진을 직접 첨부하고 붙여넣습니다.
4. 생성이 끝나면 이미지를 열어 다운로드하거나 ‘다른 이름으로 저장’으로 원본 PNG를 저장합니다.
5. 동작 시트 가져오기에서 저장한 PNG를 선택합니다.
6. 미리보기 확인 → 바탕화면에 데려오기.

새 등록은 들기·착지를 포함한 4×4 시트로 고정합니다. 시트 형식 선택은 없습니다.
기존에 저장된 시트의 형식은 유지되므로 예전 캐릭터는 기존 드래그 방식으로 동작합니다.

## 기억 보관함

각 카드 아래 ‘삭제 · 휴지통으로’를 누르면 보관함에서 빠집니다.
휴지통을 펼치고 ‘복원’을 누르면 되돌릴 수 있습니다. 파일을 영구 삭제하지 않습니다.
바탕화면에서 실행 중인 캐릭터는 삭제 후에도 유지됩니다.

## 스타일 예시 출처 (v0.9.2)

사용자가 제공한 실제 너부리 사진을 참고해 내장 imagegen으로 각각 생성했습니다.
참고사진: 20251002_072148, 20251106_075214, 20260402_073756, 20260501_055511, 20260614_232934.
지시: 흰 털 비중, 옅은 갈색 이마 무늬와 흰 콧등, 실제 눈·얼굴 비율, 회녹색 눈,
굵은 갈색 줄무늬 꼬리와 패턴 목걸이를 유지한 앉은 전신. 자연스럽게 다문 입.
픽셀 버전은 또렷한 네모 픽셀, 일러스트는 부드러운 수채·과슈 털 표현, 아이보리 배경.
생성 그림은 사진과 동일한 복제가 아니라 스타일을 적용한 재해석입니다.
결과: public/examples/nerburi-pixel.png, public/examples/nerburi-storybook.png.
## v0.9.4 — 시트 보완 후 가져오기

- 가져오기 전 16칸 검토: 크기·여백·발 위치 정렬, 빈 칸 및 경계 접촉 경고.
- 개별 이미지 교체, 칸 순서 교환, 단색 배경 제거/복원, 전체 원복.
- 배경 제거는 모서리 색과 비슷하고 가장자리와 연결된 영역만 처리하며 AI를 호출하지 않음. 체크무늬/복잡한 배경과 잘린 신체는 복원하지 않음.
- 동작 의미는 자동 판별하지 않음. 사용자 확인 후 저장하며 빈 칸은 저장 차단.
- 4×4 배치 참고 PNG 다운로드 제공. 실제 생성 결과에 글자/선을 넣지 않도록 복사 프롬프트 안내.
- 검증: 57 tests, statements 93.55%; Electron UI에서 16칸 검토→순서 변경→확인→PNG 합성→IPC 가져오기→저장 확인.
