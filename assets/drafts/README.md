# 걷기 애니메이션 초안

2026-09-16 내장 imagegen으로 사용자 제공 Touch 원본을 참고해 생성했습니다.

- `touch-walk-eye-contact.png`: 카메라를 보는 8개 걷기 포즈 초안.
- `touch-walk-profile.png`: 이동 방향을 보는 8개 걷기 포즈 초안.

이 파일은 **앱에 적용하지 않은 검토용 초안**입니다. 체크무늬가 실제 이미지에 들어 있어 투명 PNG로 사용할 수 없습니다.
프레임 크기/몸통 위치 정렬, 발의 연속 동작과 반복 연결도 추가 검증이 필요합니다.
원본 캐릭터 `../touch.png`는 수정하지 않았습니다.

사용자와 합의한 다음 방향:

1. 걸을 때는 이동 방향을 바라봅니다.
2. 가끔 멈추고 사용자를 바라본 뒤 다시 걷습니다.
3. 화면 밖으로 나가지 않고 가장자리에서 돌아섭니다.

현재 앱에는 기존 한 장짜리 원본과 가벼운 바운스가 적용되어 있습니다.
새 걷기 프레임/눈맞춤 행동과 경계 여유 보강은 아직 구현하지 않았습니다.

최종 측면 걷기 프롬프트 요약: 원본 Touch의 무늬와 정체성을 보존하고, 오른쪽을 보는 측면 8프레임 걷기 사이클을 4열×2행에 일정한 크기와 기준점으로 배치. 네 발의 자연스러운 교차 보행, 약한 꼬리 움직임, 잘리지 않은 전신, 실제 알파 투명 배경, 텍스트/테두리 없음.
