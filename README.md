# 내새꾸, 내곁에

## v0.3.2 — Windows 설치 이름 수정

설치 파일은 `release/내새꾸-내곁에-Setup-0.3.2.exe`입니다. 내부 패키지 이름을 `naesaekku`로 변경하고 실행 파일 제품 정보와 프로그램 제거 목록의 이름을 `내새꾸, 내곁에`로 설정했습니다. 새 설치의 기본 폴더 이름은 `naesaekku`입니다. 기존 설치를 업데이트하면 기존 설치 경로가 유지될 수 있습니다. 기존 데이터와 업데이트 식별을 위해 앱 ID와 사용자 데이터 경로는 유지합니다.


## v0.3.1 — 내새꾸, 내곁에

앱 표시 이름과 트레이·시작 메뉴·설치 파일 이름을 확정했습니다. 기존 사용자 데이터와 앱 ID는 유지합니다.

- 설치 파일: `release/내새꾸-내곁에-Setup-0.3.1.exe`. 별도 공간 창 없이 터치가 바탕화면에 나타납니다.
- 숨긴 터치는 작업 표시줄 알림 영역의 하트 아이콘(숨겨진 아이콘 메뉴 포함)을 클릭하면 다시 나타납니다.
- 트레이 우클릭 메뉴에 버전 정보와 업데이트 확인을 추가했습니다.
- 이번 로컬 빌드는 배포 저장소가 미연결이라 업데이트 확인 시 안내를 표시합니다. 사진 자동 캐릭터화·동작 자동 생성과 AI 편지는 이 시제품에 포함되지 않습니다.
- `npm run dist`는 설치형, `npm run dist:portable`은 포터블입니다. 사용자 데이터 경로를 유지하고 제거 시 데이터 삭제를 비활성화했습니다.

### GitHub 배포 연결

이 소스를 원하는 GitHub 저장소에 연결하고 package.json 버전과 동일한 `v0.3.0` 형식의 태그를 push하면 Windows release 작업이 테스트 후 설치 파일과 업데이트 메타데이터를 GitHub 릴리스에 올립니다. 기본 생성되는 초안 릴리스를 검토 후 게시해야 사용자에게 전달됩니다. 저장소를 직접 생성하거나 원격 게시하지는 않았습니다.

GitHub Actions의 `GITHUB_REPOSITORY`로 배포 대상을 빌드에 포함합니다. 토큰은 CI에서만 사용하고 앱에 포함하지 않습니다. 일반 사용자 배포는 공개 릴리스 저장소를 사용하세요. 수동 빌드는 같은 환경 변수를 `owner/repo`로 지정합니다. `electron-builder.config.cjs`를 통해 빌드해야 합니다.

업데이트 확인 → 사용자가 다운로드 선택 → 설치/재시작 확인 순서입니다. 현재는 자동 주기 확인 없이 메뉴에서 확인하며, 프로그램 코드 업데이트와 별도 동작 팩 다운로드는 구분됩니다. 동작 팩 원격 다운로드는 아직 구현하지 않았습니다. 실제 서버 업데이트와 코드 서명은 배포 저장소 연결 후 검증해야 합니다.

## v0.2.1 — 동작 보정

- 걷기: 기존 4장 대신 새 8장으로 교체, 10fps 재생, 프레임별 머리 위치 정렬 및 공통 크기 적용.
- 쓰다듬기: 눈을 감은 대기 자세를 유지하며 하트 위치도 고정. 서로 다른 몸 자세를 교대로 표시하지 않음.
- 클릭 흔들림: 6 DIP 미만의 커서 움직임은 드래그로 처리하지 않음. 누르는 순간에도 기존 자세·방향 유지.
- 아트 재처리 순서: `prepare-pet.mjs`로 기본 시트를 처리한 뒤 `prepare-walk.mjs`로 새 걷기 시트를 처리해야 20개 프레임과 알파 마스크가 완성됩니다.

## v0.2 — 바탕화면의 터치

이제 기본 실행 화면은 별도 작업실 없이 나타나는 투명 데스크톱 펫입니다.

- 터치를 **드래그**해 다른 모니터에 놓으면 그 모니터 안에서, 놓은 높이를 유지하며 걷고 쉽니다.
- **클릭**하면 쓰다듬기, **오른쪽 클릭**하면 간식·잠자기·걷기 메뉴를 엽니다.
- 알림 영역의 하트 아이콘을 클릭하면 숨기기/다시 보기를 전환합니다. 우클릭 메뉴에서 특정 모니터로 데려오거나 종료할 수 있습니다.
- 캐릭터 몸의 불투명 픽셀만 마우스 입력을 받습니다. 주변의 투명 영역은 뒤쪽 앱으로 클릭을 통과시킵니다.
- 걷기 4프레임, 대기/눈 감기 2프레임, 수면 2프레임, 간식 2프레임, 쓰다듬기 2프레임을 포함합니다.
- 모든 기본 동작은 저장된 그림으로 재생합니다. **API 키와 인터넷이 필요하지 않으며 실행에 AI 비용이 발생하지 않습니다.**
- 마지막 위치와 걷기 설정은 로컬 `pet-state.json`에 저장합니다. 모니터 연결 변경 시 남아 있는 화면으로 위치를 복구합니다.
- AI 편지는 다음 단계입니다. 이번 버전에는 포함되어 있지 않습니다.

터치의 동작 그림은 이전 캐릭터를 참고해 AI로 만든 1차 시안입니다. 프레임 사이 미세한 외형 차이는 추가 보정할 수 있습니다. 양쪽 방향의 걷기는 좌우 반전을 사용합니다.

### 실행 및 확인

`release/내새꾸-내곁에-Setup-0.3.1.exe` 실행 → 터치만 바탕화면에 표시됩니다.

개발 실행은 `npm start`, 기존 이미지 생성 작업실을 명시적으로 열려면 `npm run studio`입니다. 작업실의 외부 API 생성만 별도 비용이 발생합니다.

검증: `npm run test:coverage`, `npm run build`, 격리된 `ONGI_DATA_DIR`에서 `electron . --pet-smoke`.
실제 연결된 두 모니터의 네이티브 좌표와 렌더러의 5개 상태를 smoke 테스트합니다. 24시간 연속 실행 및 서로 다른 DPI 배율의 실물 모니터 조합은 아직 검증하지 않았습니다.

## 기존 이미지 생성 작업실 (선택 기능)

Windows에서 반려동물 사진을 참고해 캐릭터를 생성하고, 수정하고, 눈 깜빡임을 만들어 저장하는 개인용 데스크탑 MVP입니다.

## 실행

`release/내새꾸-내곁에-Setup-0.3.1.exe`를 실행하세요. Node.js 설치 없이 사용하는 Windows x64 설치형 앱입니다.
설정에서 본인 OpenAI API 키를 연결한 뒤 사진을 선택하고 생성합니다.
API 사용료는 본인의 API 계정에 청구되며, ChatGPT 이용권과 별개입니다.
키가 없으면 사진 가져오기, 기존 그림 보관, 픽셀 PNG 및 이미 준비된 프레임의 GIF 내보내기를 사용할 수 있습니다.

## 동작

- JPG, PNG, WebP 사진 최대 5장을 참고 이미지로 전달합니다. 한 장당 20MB 제한, 실제 이미지 디코딩 검증, 메타데이터 제거를 적용합니다.
- `gpt-image-2.5-sunburst`의 Images Edits API를 사용합니다. 캐릭터 생성, 선택한 원본 수정, 눈 깜빡임 프레임 생성이 각각 별도의 유료 요청입니다.
- 매 요청 전 사진 전송 동의가 필요하고, 한 번에 한 요청만 처리합니다. 자동 재시도하지 않으며 하루 20회로 제한합니다.
- 생성된 PNG와 참고 사진, 사용량 정보는 `%APPDATA%/Ongi Studio`에 저장합니다. 데이터 폴더를 백업하면 보관함을 보존할 수 있습니다.
- API 키는 Electron 메인 프로세스에서만 사용합니다. 저장을 선택하면 Windows 사용자 계정의 암호화 저장소를 통해 암호화됩니다. 화면이나 보관함에는 키를 반환하지 않습니다.
- 결과를 원본 PNG, 128×128 팔레트 PNG, 눈 깜빡임 GIF로 내보낼 수 있습니다.
- AI는 프레임 사이의 외형 일치를 보장하지 않습니다. 재생 화면에서 얼굴과 털 무늬가 유지됐는지 확인해주세요.
- 가져온 그림에는 ‘가져온 그림’ 표시를 붙입니다. 이전 시안은 이 앱에서 새로 생성한 결과로 표시하지 않습니다.

## 개발

Node.js 24 이상을 사용합니다.

```powershell
npm.cmd ci
node node_modules/electron/install.js
npm.cmd test
npm.cmd run test:coverage
npm.cmd run build
npm.cmd start
```

패키징:

```powershell
node scripts/icon.mjs
npm.cmd run dist
```

`ONGI_DATA_DIR`로 데이터 저장 위치를 바꿀 수 있습니다. `.env`를 앱에 포함하지 마세요.
`OPENAI_API_KEY`가 환경변수에 있으면 개인 개발용 키로 사용합니다.
브라우저에서 UI를 확인하려면 `npm run build` 이후 `npm run preview`를 사용합니다.
미리보기 서버는 루프백에만 바인딩하며 동일 출처와 세션 쿠키를 확인합니다.

## 배포 구조

현재 EXE는 **사용자가 자신의 API 키를 연결하는 개인용 버전**입니다. 개발자 공용 API 키가 포함되어 있지 않습니다.
`core`가 생성/저장 로직, `desktop`이 안전한 Electron 연결, `server/gateway.mjs`가 같은 로직의 인증된 HTTP 인터페이스입니다.
`OPENAI_API_KEY`와 `ONGI_GATEWAY_TOKEN`을 서버 환경에 설정하고 `node server/start.mjs`로 루프백 전용 게이트웨이를 실행할 수 있습니다.
여러 사용자에게 공용 생성 서비스를 배포하려면 사용자 인증, 사용자별 파일 격리/쿼터, HTTPS, 데스크탑 원격 연결을 추가해야 합니다. 현재 게이트웨이는 단일 사용자 프로토타입입니다.

## 검증 범위

실제 API 키가 없는 환경에서는 테스트용 이미지 응답으로 업로드→생성→수정→보관→GIF 흐름을 검증합니다.
유료 API를 실제 호출한 이미지 품질, 계정의 모델 사용 권한은 키 연결 후 확인해야 합니다.
Electron 실행 검증은 `electron . --smoke`를 사용합니다. 격리된 데이터 폴더로 실행하면 `smoke.json`에 실제 렌더러와 preload 연결 결과를 기록합니다.

공식 문서: https://developers.openai.com/api/docs/guides/image-generation
